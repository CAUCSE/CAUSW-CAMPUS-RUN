# 중앙대학교 캠퍼스 타이핑 게임 UI 디자인

## 목적

축제 부스의 16:9 공용 PC에서 빠르게 읽고 입력할 수 있는 나이트 네온 계열의 게임 UI를 정의한다. CAUSW 디자인 시스템을 기본 UI 기반으로 사용해 중앙대학교 소프트웨어학부 서비스와 시각적 일관성을 유지한다.

관련 기준 문서는 다음과 같다.

- 게임 설계: `docs/superpowers/specs/2026-09-02-cau-campus-typing-design.md`
- 구현 계획: `docs/superpowers/plans/2026-09-02-cau-campus-typing-game.md`
- 디자인 시스템: `https://github.com/CAUCSE/CAUSW-frontend-design-system` (확인 커밋 `2e344b279c89e574cc575e86e86f5b0bb5b6aeaf`)
- CCSSAA 로고 원본: `https://github.com/CAUCSE/CAUSW-frontend-v3/tree/develop/apps/web/public/images/ccssaa-logo.png`

## 브랜드와 로고

모든 화면의 좌측 상단에는 CAUSW 프론트엔드 v3의 `ccssaa-logo.png`를 원본 비율 224×34으로 사용한다. 구현 시 해당 파일을 `public/images/ccssaa-logo.png`로 복사하며, 투명 배경의 밝은 로고를 어두운 배경 위에만 사용한다.

로고 오른쪽에는 구분선 뒤로 `CAU CAMPUS RUN` 텍스트 워드마크를 둔다. CCSSAA 로고는 서비스의 정체성을, 워드마크는 게임의 이름을 나타낸다. 로고·워드마크 묶음은 링크나 조작 요소가 아니며, 플레이 중에는 타이머보다 시각적으로 약해야 한다.

## 디자인 시스템 적용 원칙

`@causw/design-system`을 단일 의존성으로 설치하고, 이 패키지가 제공하는 `@causw/core`, `@causw/tokens`, `@causw/icons`를 사용한다. 스타일은 CAUSW Tailwind preset과 컴포넌트를 우선 적용하고, 게임 화면의 대형 타이포그래피·16:9 레이아웃만 로컬 CSS로 보완한다.

| 용도 | CAUSW 자산 |
| --- | --- |
| 학번·별명 입력 | `Field`, `TextInput` |
| 시작·재도전·저장 재시도 | `CTAButton` 또는 `Button` |
| 로딩·저장 중 | `Spinner` |
| API 오류 | `Toast`, `Field.ErrorDescription` |
| 캠퍼스 탐험 표식 | `BuildingColored` |
| 시간·완료·오류 상태 | `Time`, `Check`, `ErrorColored` |
| 기본 색상·타이포·라운드 | `colors`, `typography`, `borderRadius` 토큰 |

디자인 시스템의 브랜드 로고 아이콘은 GitHub·카카오 등 외부 서비스용이므로 게임 헤더에 사용하지 않는다. 게임 로고는 CCSSAA PNG와 텍스트 워드마크 조합으로 고정한다.

## 색상 토큰

나이트 네온 방향은 별도의 민트 팔레트를 추가하지 않고 CAUSW 토큰의 블루·그레이·레드·그린을 사용한다. 이로써 기존 CAUSW 화면과 통일하면서 어두운 게임 화면의 대비를 확보한다.

| 역할 | 토큰 | 값 | 사용처 |
| --- | --- | --- | --- |
| 페이지 배경 | `colors.gray.900` | `#101828` | 전체 배경 |
| 카드 표면 | `colors.gray.800` | `#1E2939` | 입력·리더보드·결과 카드 |
| 경계선 | `colors.gray.700` | `#364153` | 구분선·테두리 |
| 주 강조 | `colors.blue.500` | `#4F98FF` | 포커스·진행·기본 CTA |
| 강한 강조 | `colors.blue.700` | `#237EFF` | 활성·키보드 포커스 |
| 기본 글자 | `colors.white.main` | `#FFFFFF` | 장소명·핵심 수치 |
| 보조 글자 | `colors.gray.400` | `#99A1AF` | 안내·부가 정보 |
| 오류 | `colors.red.400` | `#FD5C5F` | 오타·입력 오류·저장 실패 |
| 성공 | `colors.green.400` | `#3ED06C` | 완료 상태 |

색상만으로 상태를 전달하지 않는다. 오류에는 `오타 1회 · 수정 후 진행` 같은 문구와 `ErrorColored` 아이콘을, 완료에는 `완주 기록 저장 완료`와 `Check` 아이콘을 함께 사용한다.

## 타이포그래피와 크기

기본 서체와 무게는 CAUSW `typography` 토큰을 따른다. 시간·순위 숫자는 `typography.fontFamily.mono`를 사용해 자릿수 변화로 인한 화면 흔들림을 막는다.

| 요소 | 최소 크기 | 규칙 |
| --- | --- | --- |
| 장소명 | 52px | 굵게, 한 줄 우선, 넘치면 40px까지 축소 |
| 타이머·완주 시간 | 32px | 고정폭 숫자 |
| 순위 | 72px | 굵게, 결과 화면의 최우선 요소 |
| 입력창 글자 | 48px | 플레이 중 항상 보이는 강한 대비 |
| 버튼 | 24px | 최소 높이 64px |
| 일반 안내 | 16px | 본문 최소 크기 |

## 화면별 구성

### 대기 화면 (`/`)

헤더에는 CCSSAA 로고·구분선·워드마크를 둔다. 본문은 1280px 이상에서 좌측 55%의 시작 카드와 우측 45%의 Top 10 리더보드로 나눈다. 시작 카드에는 `BuildingColored` 아이콘, 한 줄 게임 설명, 학번 `Field`, 별명 `Field`, 큰 시작 CTA를 순서대로 둔다.

학번은 입력 중에만 표시하며, 세션 생성 후 어느 화면에서도 렌더링하지 않는다. API 검증 실패는 해당 `Field.ErrorDescription` 아래에 표시한다. 리더보드는 순위·별명·기록·오타 열만 보여 준다.

### 플레이 화면 (`/play.html`)

헤더는 로고·워드마크를 작게 유지하고, 우측에는 `Time` 아이콘과 경과 타이머를 둔다. 중앙에는 현재 순번, 장소명, 입력창을 세로 정렬한다. 화면 하단에는 오타 수와 즉시 피드백만 둔다.

입력창은 CAUSW `TextInput`을 기반으로 하되 게임 전용 CSS에서 48px 글자 크기와 최소 72px 높이를 준다. 기본·포커스 상태는 블루, 오타 상태는 레드로 표시한다. 키보드 포커스는 화면 전환 및 모든 키 입력 뒤에도 입력창으로 반환한다.

### 결과 화면 (`/result.html`)

완주 상태에는 `Check` 아이콘과 `완주 기록 저장 완료` 문구를 먼저 보여 준다. 그 아래에 큰 순위, 완주 시간, 오타 수, 최신 Top 10, 재도전 CTA 순서로 배치한다. 저장 실패 시에는 `ErrorColored` 아이콘·오류 문구·`다시 저장` 버튼을 보여 주며 결과 화면으로 이동하지 않는다.

## 반응형·접근성 규칙

- 기준 해상도는 1280×720이며, 세 페이지 모두 세로 스크롤 없이 핵심 조작을 완료해야 한다.
- 가로폭 960px 미만에서는 대기 화면의 시작 카드와 리더보드를 세로로 쌓는다.
- 모든 조작 요소는 키보드로 접근 가능하고, `:focus-visible`에서 최소 3px의 `colors.blue.500` 윤곽선을 표시한다.
- 입력 오류·네트워크 오류·기록 저장 상태는 스크린 리더가 읽을 수 있는 상태 영역으로도 제공한다.
- 공용 PC에서 마우스 없이 바로 시작할 수 있도록 대기 화면 로드 직후 학번 입력에 포커스를 둔다. 플레이 화면에서는 타이핑 입력창에 포커스를 둔다.

## 구현 검수 기준

- CCSSAA 로고가 모든 페이지의 동일 위치에 흐리지 않게 표시된다.
- `@causw/design-system`의 입력·버튼·피드백 컴포넌트와 토큰을 사용한다.
- 공개 리더보드·결과 화면 어디에도 학번이 보이지 않는다.
- 1280×720에서 장소명, 입력창, 타이머, 오타 수, 주요 CTA가 한 화면에 보인다.
- 기본·포커스·오류·비활성·로딩·완료 상태를 확인할 수 있다.
